# Pokédex (React Native + Expo)
Setup:
  npx create-expo-app pokedex-<student-no> --template blank
  cd pokedex-<student-no>
  npx expo install @react-navigation/native @react-navigation/bottom-tabs @react-navigation/native-stack react-native-screens react-native-safe-area-context @react-native-async-storage/async-storage
Copy App.js and the src/ folder into the project (replace App.js), edit src/config.js, then run: npx expo start
